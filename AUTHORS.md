## Contributions

Contributions are accepted under `GOVERNANCE.md` and require a Developer Certificate of
Origin sign-off ([DCO 1.1](https://developercertificate.org/)): every commit must carry a
`Signed-off-by:` line matching its author. `git commit -s` adds it.

why sign-off was chosen over a CLA.

## Why this file exists

`LICENSE` grants usage rights. This file records **who owns the work**. The two are
separate documents with separate jobs: a licensee may use the code, but ownership
never moves. Where ownership is concerned, this file and `GOVERNANCE.md` govern; no
other document, README sentence, or organisational page can override them.

Moving this repository into an organisation does not change the copyright holder.
The organisation holds no ownership; it hosts and uses the work under permission.
